Lverage Visual Guide

From gene DNA to candidate binding motifs

Lverage is a transcription-factor motif transfer pipeline. It starts with gene DNA, finds a likely protein, verifies its DNA-binding domain, searches for orthologs in other species, checks whether that DNA-binding domain is conserved, and uses those orthologs to infer candidate motifs from JASPAR.

Main Input FASTA files containing one gene per file, possibly with multiple scaffolds.
Core Filter Only orthologs with sufficiently conserved DNA-binding domains are trusted.
Main Output A TSV table linking genes, ortholog evidence, DBD similarity, and motif hits.

Pipeline Flow

01

Read gene FASTA records

Lverage loads all DNA records from one FASTA file and treats them as belonging to the same gene. This allows one gene to be represented by a single sequence or by multiple scaffolds.

Input DNA One gene per file Scaffold-aware
02

Translate candidate ORFs

Each DNA sequence is translated with ORF finding. Candidate protein products are deduplicated, ranked by length, and screened one by one until Lverage finds a plausible transcription-factor protein.

ORF search Top candidates only Protein inference
03

Scan for DNA-binding domains

Candidate proteins are sent to the domain scanner. Lverage keeps only ORFs that contain at least one PFAM accession from the user-provided valid DBD list. This is where the pipeline decides whether the ORF looks like a real transcription factor.

Pfam/DBD scan PFAM accession filter TF gating step
04

Search ortholog proteins

The selected protein sequence is used as a BLASTP query against user-selected species. Lverage keeps ortholog candidates along with accession, species, e-value, percent identity, query coverage, and sequence.

Remote or local BLAST Species filter Annotation cleanup
05

Map ortholog DBDs to gene DBDs

Every ortholog protein is scanned for domains again. Lverage matches ortholog domains back to the gene’s DBD list by PFAM accession so that each ortholog is evaluated against the same DBD family as the query gene.

Ortholog domain scan PFAM family matching Ordered DBD mapping
06

Measure DBD conservation

The amino-acid span for each gene DBD is globally aligned to the matching ortholog DBD span. Lverage converts that alignment into a similarity score and keeps only orthologs whose DBD similarity passes the configured identity threshold.

Global alignment DBD-only comparison Identity threshold
07

Infer motifs from ortholog evidence

Orthologs that pass the DBD conservation filter are used to query the motif database. In the current LverageOld code path, JASPAR is the motif source. If the ortholog protein is very long, the ortholog sequence is cropped to a window centered on the ortholog’s matching DBD before inference.

JASPAR inference Ortholog-driven evidence Long-sequence windowing
08

Write evidence-rich motif records

Each accepted motif hit is written alongside the supporting ortholog metadata and the gene-versus-ortholog DBD similarity. The final output is a TSV that explains not just which motif was found, but why Lverage considered it transferable.

TSV output Traceable evidence Gene + ortholog + motif

Key Decision Points

No valid ORF with a DBD

If no translated ORF contains a valid DNA-binding domain, the pipeline stops for that gene.

No usable orthologs

BLAST hits may be filtered out for species mapping issues, poor annotation quality, or lack of matching domains.

DBD not conserved enough

An ortholog may exist, but it is not used for motif transfer unless its DBD is similar enough to the query gene’s DBD.

Motif transfer succeeds

A conserved ortholog with a compatible DBD contributes candidate motif hits, which are added to the final report.

Why this pipeline is built this way

Lverage is intentionally conservative. It does not transfer motifs based only on whole-protein similarity. Instead, it focuses on DNA-binding domains, because those are the parts of transcription factors most directly tied to DNA recognition.

  • It starts from raw gene DNA and works upward to protein and motif inference.
  • It uses ortholog species as evidence sources rather than guessing motifs from the query alone.
  • It records the evidence chain behind every motif hit.

One-sentence summary

Lverage takes a gene sequence, finds a likely transcription factor protein, verifies its DNA-binding domains, finds orthologs with conserved DBDs, and uses those orthologs to infer candidate binding motifs.
